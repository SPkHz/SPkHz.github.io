# Security policy

Please report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/SPkHz/SPkHz.github.io/security/advisories/new).

If private reporting is unavailable, contact Steven.Placzek@ieee.org.
Include the affected URL or component, reproduction steps, and expected impact.
Do not disclose credentials or publish exploit details in a public issue.

The supported website is https://spkhz.github.io/. Public discovery information
is available at https://spkhz.github.io/.well-known/security.txt.
