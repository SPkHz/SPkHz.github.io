This lab explores **non-ideal characteristics** of the **LM741** operational amplifier using a set of DC test circuits and frequency/time-domain measurements:

- **DC imperfections:** input offset voltage \(V*{OS}\) and input bias currents \(I*{BN}\), \(I\_{BP}\)
- **Dynamic limits:** **slew rate** (large-signal step response)
- **Small-signal behavior:** **Bode magnitude**, \(f*{H}\) (−3 dB frequency), and \(f*{t}\) (unity-gain / gain-bandwidth)

**Tools:** LTspice (operating point, transient, AC analysis) + MATLAB (solving for \(V*{OS}\), \(I*{BN}\), \(I\_{BP}\)).

---

## Key results

| Quantity                                 |                       Result |
| ---------------------------------------- | ---------------------------: |
| Input offset voltage \(V\_{OS}\)         |              **999.9573 µV** |
| Input bias current (−) \(I\_{BN}\)       |              **101.8587 nA** |
| Input bias current (+) \(I\_{BP}\)       |               **57.8650 nA** |
| Slew rate (measured from \(d v_o / dt\)) |              **0.3235 V/µs** |

| −3 dB frequency \(f_H\)                  |              **91.2795 kHz** |
| Unity-gain / \(f_t\)                     |             **954.9926 kHz** |
| Gain-bandwidth product (GBP)             |               **1.0039 MHz** |

## Part D — Bode plot, \(f_H\), and gain-bandwidth

An AC sweep from **100 Hz to 10 MHz** was used to measure \(A_v(f)\), then:

- \(f_H\) was found at the **−3 dB** point from the low-frequency gain
- \(f_t\) was found at (approximately) **0 dB** gain
- \(\text{GBP} \approx A_v(0) \cdot f_H\)
