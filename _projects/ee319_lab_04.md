This project examines the input-output characteristics of a **common source MOSFET amplifier** employing an active current source load. The amplifier is biased to achieve $$ V_O \approx 0 \text{ V} $$ at the operating point, and the small-signal voltage gain is determined through hand calculations, LTspice simulation, and hardware measurements using the Analog Discovery Studio.

## Circuit Overview

The amplifier topology uses the **ALD1105** dual complementary pair IC containing matched NMOS (ALD1106) and PMOS (ALD1107) transistors. The circuit implements a common source configuration with Q1 (NMOS) as the input transistor and Q2 (PMOS) as an active current source load, achieving high voltage gain through the high output impedance of the current mirror.

## DC Operating Point Analysis

The bias current is established by the PMOS current mirror (Q3) through resistor R. Q3 operates with its gate connected to its drain, forcing it into saturation. The current is mirrored to Q2, which loads the common source stage formed by Q1.

### Hand Calculation Methodology

The analysis proceeds in three stages:

**1. Q3 (PMOS Current Source Reference):** Solving the quadratic equation for overdrive voltage:

$$
R \cdot K_3 \cdot V_{ov3}^2 + V_{ov3} + (|V_{Tp}| - V_{DD} - V_{SS}) = 0
$$

**2. Q2 (PMOS Active Load):** The current mirror copies the reference current:

$$
I_{D2} = I_{D3} = K_3 \cdot V_{ov3}^2
$$

**3. Q1 (NMOS Input Stage):** With $$ V_O = 0 $$ at the operating point:

$$
V_{ov1} = \sqrt{\frac{I_{D1}}{K_1}}, \quad V_I = V_{GS1} + V_{S1} = V_{ov1} + V_{Tn} - V_{SS}
$$

### Small-Signal Parameters

The low-frequency voltage gain derives from the small-signal model:

$$
A_{v(LF)} = \frac{-g_{m1}}{g_{o1} + g_{o2}}
$$

where the transconductance and output conductance account for channel-length modulation:

$$
g_m = \frac{2 I_D}{|V_{ov}|} \sqrt{1 + \lambda |V_{DS}|}, \quad g_o = \frac{\lambda I_D}{1 + \lambda |V_{DS}|}
$$

## Observations

**Gain Agreement:** Hand calculations, LTspice simulation, and hardware measurements agree within 4% for $$ A_{v(LF)} $$, demonstrating the accuracy of the square-law MOSFET model with channel-length modulation.

**Output Swing Asymmetry:** The positive and negative output swing limits differ due to the asymmetric biasing—Q1 clips when it enters triode region (positive swing), while Q2 clips when it saturates hard (negative swing).

**Current Source Loading:** The PMOS active load provides significantly higher impedance than a passive resistor of equivalent DC drop, resulting in the high voltage gain (~40 V/V) from a single stage.

## Analysis Code

The MATLAB analysis script performs:
- DC operating point calculations for all three transistors
- Small-signal parameter extraction with channel-length modulation
- Gain computation and maximum swing analysis
- Comparison with LTspice transfer function results

Key equations implemented:

```matlab
% Small-signal parameters with channel-length modulation
XA1 = 1 + lambda_n * abs(VDS1);
gm1 = (2*ID1 / abs(Vov1)) * sqrt(XA1);
go1 = (lambda_n * ID1) / XA1;
ro1 = 1 / go1;

% Voltage gain
Go = go1 + go2;  % Q2 provides the load impedance
Av_LF = (-gm1) / Go;
```
