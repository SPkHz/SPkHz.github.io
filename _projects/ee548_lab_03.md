This lab characterizes **polarization-dependent loss (PDL)** for a silicon-photonic device under test (DUT) by sweeping wavelength in the C-band while cycling the input state-of-polarization (SOP) through four calibrated states. In addition to the PDL result itself, the measured transmission traces show clear **spectral fringes** whose **free spectral range (FSR)** can be used to infer an effective cavity/path length and to diagnose parasitic reflections.

## Definitions used

The measurement software reports insertion loss relative to the monitored input power.

```text
IL(dB)  = 10 log10(Pout / Pin)
PDL(dB) = ILmax − ILmin
```

- **ILmax / ILmin** are the insertion-loss values corresponding to the SOPs that yield the **maximum** and **minimum** transmission, respectively.
- **PDL** is therefore the spread between best-case and worst-case transmission caused solely by polarization.

> Note on sign convention: many instruments report IL as a negative number (because Pout < Pin). In that case, a value like −30 dB corresponds to 30 dB loss.

---

## Mueller–Stokes 4-state method (overview)

Instead of continuously scrambling polarization, the lab uses a **4-state measurement** commonly described in standards like **IEC 61300-3-12**:

1. Launch **four known input SOPs** (e.g., LH, LV, +45° linear, RHC).
2. Record transmitted power at each wavelength for each SOP.
3. Use Mueller/Stokes relations to estimate the device transmission extremes, yielding:
   - **ILmax(λ)** (best transmission / least loss)
   - **ILmin(λ)** (worst transmission / most loss)
4. Compute **PDL(λ) = ILmax(λ) − ILmin(λ)**.

This method is efficient (few SOP states per wavelength) while still estimating the true polarization-dependent extremes.

## Fringe analysis: FSR → effective cavity length

The wavelength-periodic ripple can be summarized by its **free spectral range** (FSR). The graded report measured:

- FSR(Input) ≈ FSR(Through) ≈ **0.2088 nm**
- FSR(Cross) ≈ **0.1239 nm**

To convert from wavelength spacing to frequency spacing around a center wavelength λ0:

```text
Δν ≈ (c / λ0^2) · Δλ
```

Using λ0 ≈ 1525 nm (midpoint of the 1520–1530 nm sweep):

| Port    | FSR Δλ (nm) | Δν (GHz) @ 1525 nm | L (mm) if ng = 1.46 | L (mm) if ng = 4.0 |
| ------- | ----------: | -----------------: | ------------------: | -----------------: |
| Input   |      0.2088 |              26.92 |                3.81 |               1.39 |
| Through |      0.2088 |              26.92 |                3.81 |               1.39 |
| Cross   |      0.1239 |              15.97 |                6.43 |               2.35 |

(Using 1550 nm instead changes Δν by only a few percent.)

Length is estimated using a simple Fabry–Perot-style relationship:

```text
FSR ≈ c / (2 ng L)  →  L ≈ c / (2 ng FSR)
```

**Interpretation:**

- The equality **FSR(Input) ≈ FSR(Through)** suggests a shared dominant cavity/path.
- The smaller FSR at the **Cross** port indicates a **longer effective optical length** (either due to routing, port-specific reflections, or a different dominant etalon).

## Discussion and takeaways

- **High PDL (~15 dB) is expected in many silicon-photonic waveguides** because the structure is typically optimized for TE-like modes; TM-like modes can suffer weaker confinement and higher loss.
- **The ripple/FSR behavior is a useful diagnostic.** Fringe spacing at different ports can reveal whether a common parasitic cavity dominates, or whether a particular port introduces extra reflections/length.
- **Measurement hygiene matters:** angled/low-reflection terminations, stable fiber handling, and (when possible) polarization-maintaining alignment reduce artifacts and improve the reliability of PDL inference.

## Reproducibility notes (analysis workflow)

The instrument software logs wavelength-resolved results (including ILmin, ILmax, ILavg, and PDL) to CSV. A simple Python workflow can:

1. Load the CSV columns of interest.
2. Plot IL and PDL versus wavelength.
3. Compute FSR by detecting consecutive valleys in the transmission trace.

Example FSR helper (valley-based):

```python
import numpy as np
from scipy.signal import find_peaks

def fsr_from_valleys(wavelength_nm, il_db, prominence=0.1):
    """Return mean valley-to-valley spacing in nm."""
    idx, _ = find_peaks(-il_db, prominence=prominence)  # valleys are peaks of -il_db
    if len(idx) < 2:
        return float("nan")
    return float(np.mean(np.diff(wavelength_nm[idx])))
```
