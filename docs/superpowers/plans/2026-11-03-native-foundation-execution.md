# Native foundation implementation evidence

The [approved plan](2026-11-03-native-foundation.md) and
[design](../specs/2026-11-03-native-foundation.md) control this delivery.
[The baseline](2026-11-03-native-foundation-baseline.md) records the bounded
cleanup separately. `NEXT_PLAN.md` remains the canonical backlog. These documents
and the browser dependency inventory are excluded from publication.

The native foundation preserves all 55 projects, ordinary page routes, technical
article text, equations, tables, code, thumbnails, board imagery, people page,
search destinations/shortcuts, themes, zoom, tabs, sliders and bibliography.
Navigation and tab contents remain available without JavaScript. The menu exposes
`window.SiteUI.closeNavigation()`; both pointer and keyboard search use it.
Sidebar links are generated by Jekyll TOC and highlighted by IntersectionObserver.
Tables scroll locally, while bibliography controls, copying, progress and the
native back-to-top button remain keyboard usable. Theme selection works when
storage access throws. Image fallback removes sources only in its own picture.

Bootstrap/MDB/jQuery, Bootstrap-Toc/Table, Masonry/imagesLoaded and obsolete
initializers leave the runtime. Unused Distill/CV/typogram and full icon imports
leave the core Sass path. Unused Academicons/Scholar Icons CSS is excluded from
publication; existing font files and licensing remain. No technical source file
or image URL is retired by the foundation replacement.

## Preservation and regressions

All 204 ordinary page routes and normalized article text match the baseline;
code blocks match exactly. All six rendered technical-download destinations and
SHA-256 hashes match. Of the other retained non-CSS/JavaScript assets, 3,242 files
match byte for byte, four JSON assets preserve equal parsed data after removal
of the JSON minifier, and one generated technical HTML document preserves its
article content and code under the new shared layout. The approved Plotly/video
retirement is the only removed HTML/sample destination.

The cache filter retains `bust_css_cache(path)`. The post-write hook resolves
render-time markers from final SHA-256 stylesheet bytes before validation, also
fingerprinting other local stylesheet links. File-backed tests cover stable and
changed bytes, baseurl/query/fragment preservation, relative stylesheets, repeated
writes, missing paths, unsafe paths and unresolved markers. Third-party SRI stays
unchanged. Every generated local stylesheet link was checked against emitted bytes.

Hostile quoted, backslash, Unicode and HTML-like search strings first reproduced
invalid JavaScript. Liquid JSON serialization now preserves readable inert
strings and destination URL encoding, including collection ids. Browser regressions
first reproduced hidden jQuery coupling, blocked-storage failure and global picture
fallback, then passed after replacement. Sidebar scroll targeting no longer double
counts header offset. Back-to-top is a native keyboard-operable button.

PASS: 46 standard-library tests with Node/npm unavailable and no root node_modules;
frozen Bundler checks; network-disabled cold/warm production generation; both
publication validators; negative private/portrait/backlog/retired-sample fixtures
and positive security.txt fixture; generated/first-party JavaScript syntax checks.

PASS: 144 rendering cases at 390/768/1440 pixels, light/dark themes, 100%/200% zoom,
normal/reduced motion, with no status, overflow, contrast or script-error cases.
All 24 keyboard/widget combinations pass, with 4.5:1 normal-text and 3:1 applicable
focus/control thresholds. Seven focused browser scenarios cover menu/focus/search,
blocked storage, picture fallback, bibliography, sidebar, back-to-top/progress and
JavaScript-disabled navigation/tab contents. Screenshots stay outside publication.

## Build protection and maintenance

`generate` runs Ruby/Python generation tests and publication validation without
project Node setup. `checks`, retaining the required **Build and validate** name,
uses `always()` and rejects failed, cancelled or skipped generation as its first
gate. It downloads only the current run's named Pages artifact, requires digest
matches, validates all tar members before extraction, rejects paths/links/special
files and syntax-checks the extracted artifact without executing its content.
Deployment depends on both jobs and publishes the same artifact without rebuilding.
Main deployment is not cancelled by newer runs; superseded PR runs are cancelled.

The official download-artifact v8.0.2 release and verified commit
`9000827ccba6bdab643e8b6fd33ac0654aef8333` were reviewed. The operator ran the
approved v0.4.0 lock generator after local connections initially failed. Subsequent
verification and regeneration idempotence pass; no lock was hand-edited.
All prior action pins and transitive locks remain unchanged.

Routine groups run on the first and fifteenth at 09:00 America/New_York. Separate
security-update groups preserve updates between routine windows. Managed security
updates, secret scanning and push protection remain enabled. Human review and the
prohibition on automatic merging remain in force. Dependency tests derive exact
versions from manifests and enforce names, integrity and lock/toolchain agreement.

PASS: isolated formatter checks twice, actionlint, warning-free ShellCheck for all
tracked shell scripts, whitespace checks and redacted tree/history secret scans
with zero findings. Network-free source-only dependency scan: 3 manifests,
115 dependency entries, complete, zero warnings. The baseline scan counted 38:
its Git-prefixed Ruby lock exposed one entry, while the registry-only lock now
exposes 106; npm lock entries independently drop 34 → 7. Scanner counts are not
an overall dependency-risk score or a host-exposure claim.
