EE-548 Lab 05 — Thermo-Optic Phase Modulation in a Silicon MZI

Micro-heater tuning of a silicon Mach–Zehnder interferometer (Vπ ≈ 3.05 V, Pπ ≈ 48.5 mW, ER ≈ 33 dB).

Course: EE-548 — Silicon Photonics
Lab date: 2025-11-12
Topic: Thermo-optic phase modulation using a micro-heater integrated on one arm of a silicon MZI

Overview

A silicon photonic Mach–Zehnder interferometer (MZI) can be used as an intensity modulator by inducing a phase shift in one arm and recombining the two paths. In this lab, a resistive micro-heater was driven with a DC source-measure unit (SMU) to heat one arm; silicon’s thermo-optic coefficient converts that temperature rise into a refractive-index change and therefore a controllable phase delay.

Key results (from the corrected, digitized measurement plots)

Metric Value
Half-wave switching voltage, (V_{\pi}) (\approx 3.05\,\text{V})
Electrical power for (\pi) phase shift, (P_{\pi}) (\approx 48.5\,\text{mW})

Small-signal 3 dB bandwidth (thermal) (\approx 12.0\,\text{kHz})

Background (what’s being measured)

Thermo-optic phase shift

Heating one arm changes the refractive index by (\Delta n = (dn/dT)\Delta T), producing a phase shift

[ \Delta \phi = \frac{2\pi}{\lambda}\,\Delta n\,L. ]

For moderate temperature excursions, (dn/dT) is approximately constant, so (\Delta\phi) is approximately linear with electrical heater power.

MZI transfer function

Neglecting imbalance and loss, the MZI intensity follows

[ P{\mathrm{out}} = P{\mathrm{in}}\cos^2\left(\frac{\Delta\phi}{2}\right). ]

In this lab the operating wavelength was chosen at (or very near) a destructive interference null at 0 V, so increasing heater power moves the interferometer toward constructive interference.

Experimental setup (high level)

  1. Use a broadband source + optical spectrum analyzer (OSA) to locate an interference trough near 1550 nm.
  2. Switch to a tunable laser at that trough wavelength (starting the device “off”).
  3. Sweep heater voltage with an SMU, recording current and output optical power.
  4. Compute heater electrical power (P = VI), and extract (V{\pi}), (P{\pi}), and extinction ratio.
Conceptual MZI phase modulator: a resistive heater raises the temperature of one arm, inducing \(\Delta\phi(T)\) and changing the interference at the output.

Results

1) Optical output vs heater electrical power

Output optical power (dBm) versus heater electrical power (mW). The peak corresponds to approximately a \(\pi\)-phase shift from the heater (first constructive maximum in the monitored port).

2) Extracted phase shift vs heater power (linear thermo-optic behavior)

Using the normalized MZI output (P_\mathrm{norm}) (starting from destructive interference), the phase is extracted via

[ \cos(\Delta\phi) = 1 - 2P_{\mathrm{norm}},\quad 0\le\Delta\phi\le\pi. ]

Extracted phase shift shows an approximately linear relationship with heater power. The linear fit indicates \(P_\pi\approx 48.5\,\text{mW}\) for a \(\pi\) phase shift.

3) MZI transfer function (normalized output vs heater voltage)

For a roughly constant heater resistance (R), electrical power scales as (P\approx V^2/R), so the transfer function is periodic in the electrically induced phase.

Normalized MZI output versus heater voltage with an overlaid cosine model. The extracted half-wave point is \(V_\pi\approx 3.05\,\text{V}\).

(Optional) Dynamic behavior: thermal small-signal response

Thermo-optic modulators are typically bandwidth-limited by heat diffusion. A first-order thermal model behaves like a low-pass filter with a 3 dB corner, (f{3\text{dB}}), related to the thermal time constant (\tau\approx 1/(2\pi f{3\text{dB}})).

Small-signal response consistent with a thermal low-pass process. Here \(f_{3\text{dB}}\approx 12.0\,\text{kHz}\) implies \(\tau\approx 13\,\mu\text{s}\).
